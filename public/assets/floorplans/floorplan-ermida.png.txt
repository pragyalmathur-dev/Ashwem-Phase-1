# The interactive viewer under Ashwem Phase 1 parses individual villa floor plan paths 
# dynamically in the client state. To prevent missing physical images, all asset files 
# MUST comply exactly with the following schema:
#
# ─────────────────────────────────────────────────────────────────────────
# PATH FORMULA:
# /assets/floorplans/LE_{unitNumber}_{floorLevel}_{dimensionMode}.jpg
# ─────────────────────────────────────────────────────────────────────────
#
# PARAMETERS EXPLAINED:
# 1. Prefix:         LE (constant for La Ermida villas)
# 2. unitNumber:     Two-digit padded identifier (e.g., 01, 02, ..., 12, 14, ..., 18)
# 3. floorLevel:     GF (Ground Floor) or FF (First Floor)
# 4. dimensionMode:  WD (With Dimensions) or WOD (Without Dimensions)
#
